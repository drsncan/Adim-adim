# Adım Adım - İnteraktif Odaklanma ve Verimlilik Uygulaması

## 📖 Proje Hakkında

**Adım Adım**, kullanıcıların günlük hedeflerine odaklanmasını sağlayan, süreli çalışma oturumları oluşturabildiği ve ilerlemelerini takip edebildiği bir mobil verimlilik uygulamasıdır.

Uygulama; görev yönetimi, odaklanma seansları, not alma, ilerleme takibi ve streak sistemi gibi özellikler sunar.

---

## 🎯 Proje Amaçları

- Görev ve etkinlik planlamasını kolaylaştırmak
- Odaklanma süresini ölçmek ve takip etmek
- Günlük ve haftalık ilerlemeyi raporlamak
- Kullanıcı motivasyonunu artırmak
- Süreklilik alışkanlığı kazandırmak

---

## ✨ Temel Özellikler

### 📝 Görev Yönetimi
- Yeni görev oluşturma
- Görev düzenleme ve silme
- Görev tamamlama takibi

### ⏱️ Odaklanma Zamanlayıcısı
- Çalışma ve mola süreleri belirleme
- Başlat / Durdur / Sıfırla işlemleri
- Geri sayım sayacı
- İlerleme çubuğu animasyonu

### 📒 Not Alma
- Odaklanma oturumu sırasında not ekleme
- Görev bazlı not saklama

### 📊 İlerleme Takibi
- Günlük çalışma süresi
- Haftalık çalışma süresi
- Tamamlanan görev sayısı
- İstatistik ekranı

### 🔥 Streak Sistemi
- Ardışık kullanım günlerini takip etme

---

## 🛠️ Kullanılan Teknolojiler

- React Native (Expo)
- React Navigation
- Zustand / Redux Toolkit
- AsyncStorage
- react-native-reanimated
- expo-notifications
- React Native Paper

---

## 🚀 Kurulum

```bash
git clone https://github.com/drsncan/Adim-adim.git
cd Adim-adim
npm install
npx expo start
```

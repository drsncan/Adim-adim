# Adım Adım 🚀

Adım Adım, kişisel hedeflerinizi, görevlerinizi ve günlük rutinlerinizi takip etmenize yardımcı olan, React Native ve Expo kullanılarak geliştirilmiş bir mobil üretkenlik uygulamasıdır.

## 📱 Proje Hakkında

Bu proje, kullanıcıların hedeflerine adım adım ulaşmalarına ve zamanlarını daha verimli yönetmelerine olanak tanımak amacıyla tasarlanmıştır. Uygulama, modern ve kullanıcı dostu bir arayüz ile geliştirilmiştir.

### 🛠 Kullanılan Teknolojiler

*   **Framework:** [React Native](https://reactnative.dev/)
*   **Geliştirme Ortamı:** [Expo](https://expo.dev/)
